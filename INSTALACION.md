# Control Horario V3.2 — Instalación para trabajadores

## Enlace de instalación

La aplicación se distribuye como PWA desde GitHub Pages:

https://aplicacionesindustriales-alt.github.io/Control-Horario/

No es necesario descargar un programa ni instalar Java. Cada trabajador puede instalarla directamente desde el navegador.

## Android

1. Enviar al trabajador el enlace anterior por WhatsApp.
2. Abrirlo con Chrome.
3. Esperar a que cargue la aplicación.
4. En el menú de Chrome seleccionar **Instalar aplicación** o **Añadir a pantalla de inicio**.
5. Confirmar.
6. Aparecerá el icono **Control Horario** en el móvil y podrá abrirse como una aplicación normal.

## iPhone / iPad

1. Abrir el enlace con Safari.
2. Pulsar **Compartir**.
3. Seleccionar **Añadir a pantalla de inicio**.
4. Confirmar.

## Windows / PC

1. Abrir el enlace con Chrome o Edge.
2. Utilizar el icono de instalación que aparece en la barra de direcciones, o el menú del navegador → **Instalar Control Horario**.
3. Confirmar la instalación.
4. La aplicación quedará disponible como una aplicación independiente.

## Uso sin conexión

Una vez instalada y abierta al menos una vez con conexión, la PWA puede funcionar sin conexión para las funciones almacenadas localmente en el dispositivo.

## Importante sobre los datos de esta versión

La V3.2 actual guarda los datos en el navegador/dispositivo mediante `localStorage`. Por tanto, cada móvil o PC mantiene sus propios datos.

Antes de cambiar de dispositivo, utilizar **Administración → Copia de seguridad → Exportar copia** y, en el nuevo dispositivo, **Restaurar copia**.

## Distribución recomendada a la plantilla

Enviar siempre el mismo enlace oficial. No es necesario instalar archivos APK, EXE ni realizar instalaciones manuales.

Cada trabajador debe instalar la PWA en su propio móvil o PC.
